### 02 · 「智析 BizInsight」｜电商经营分析 Agent

> **不是“会查数”的 ChatBI，而是帮运营完成一次可追溯、可验证的经营分析。**

**关键词**：B 端 · AI Agent · 数据分析 · 经营诊断 · Evidence Gate · Human-in-the-loop · Eval

智析面向电商运营，聚焦一个高频任务：

**发现销售异常 → 找主要贡献 → 判断证据 → 验证假设 → 形成复盘。**

它的核心产品判断是：传统 BI 已经能很好地回答“发生了什么”，真正需要降低的是用户自己组织“下一步看什么、为什么、还缺什么证据”的成本。

### 为什么值得看

**1. LLM 不负责算数**

自然语言理解、任务编排和解释交给 LLM；GMV、趋势、环比 / 同比、贡献拆解等关键数值由确定性计算引擎产生。

**2. Contribution ≠ Causality**

先回答“谁贡献了变化”，再寻找“为什么变化”。产品将结果拆成：

`事实 → 贡献证据 → 关联证据 → 待验证假设 → 验证路径`

证据不足时不强行下因果结论。

**3. 人只在关键节点拍板**

字段映射确认 → 证据缺口决策 → 最终经营判断。

Agent 只分析、解释和建议验证方式，不替用户调价、补货或投放。

## 智析：3 分钟看懂

```text
用户：帮我看一下最近两周销售为什么下降
                ↓
        Intent + Schema 校验
                ↓
          数据质量检查
                ↓
      趋势 / 对比 / 异常检测
                ↓
      指标贡献拆解 + 守恒校验
                ↓
          因素扫描
                ↓
         Evidence Gate
          ↙          ↘
     证据充分       证据不足
        ↓              ↓
      假设验证      暴露证据缺口
        ↘              ↙
          复盘摘要 + 下一步
```

### 一个典型结果

> GMV 环比下降 14.2%  
> 商品 A 贡献总下降的 44%  
> 点击率与销量同期下降  
> **但当前数据不足以证明因果**  
> 补充库存数据后，“缺货导致下滑”假设不成立  
> → 转向验证曝光 / 流量

这体现了智析最核心的设计：**宁可少说、不说错。**

## 产品设计深度

| 层次 | 我重点解决的问题 |
| --- | --- |
| Product | 核心任务到底是什么，而不是功能堆什么 |
| Agent | 意图识别、State、工具路由、分支与 HITL |
| Data / Logic | 确定性计算、贡献拆解、守恒校验 |
| Trust | Evidence Gate、事实一致性、假设验证 |
| Eval | 任务理解、计算正确性、解释质量、红线集 |
| Safety | 权限、审计、数据隔离、越权防御 |
