### 02 · 「智析 BizInsight」｜电商数据分析 Agent

**关键词**：B 端 · AI Agent · 数据分析 · 经营诊断 · 证据链 · 人机协作 · AI 产品化

一个面向“店铺电商运营与平台电商运营”的经营分析 Agent，重点解决“发现经营异常后，不知道下一步该分析什么、哪些数据能支持判断，以及如何快速形成可信复盘”的问题。

它不是把传统 BI 搬进聊天框，也不是一个只会生成 SQL 的 ChatBI，而是让 Agent 参与一次完整的经营分析过程：从发现异常，到拆解指标、定位主要贡献、寻找关联因素、验证假设，最后形成可复核的复盘结论。

#### 产品流程

```text
上传数据
   ↓
字段识别 / 人工确认
   ↓
数据质量检查
   ↓
提出经营问题
   ↓
Agent 理解意图
   ↓
趋势 / 对比分析
   ↓
异常发现
   ↓
指标拆解 / 贡献分析
   ↓
因素扫描
   ↓
证据判断
   ↓
假设验证
   ↓
复盘摘要
```

核心原则是：**先回答“谁贡献了变化”，再讨论“为什么变化”；证据不足时停止向下推理，而不是让模型猜一个原因。**

#### 核心功能

| 功能 | 解决什么问题 |
| --- | --- |
| **文件上传与字段映射** | 快速接入 CSV / Excel，并将原始字段映射为可分析的业务字段 |
| **数据质量检查** | 在分析前发现缺失字段、时间异常、重复记录等问题，避免脏数据进入结论链路 |
| **指标趋势与异常发现** | 快速定位销售、GMV 等经营指标的异常变化 |
| **指标拆解与贡献分析** | 回答“整体下降主要是谁贡献的”，并通过守恒校验保证结果可核对 |
| **因素扫描** | 围绕流量、点击率、转化率、客单价、库存、活动、渠道等寻找候选因素 |
| **假设验证** | 对简单经营假设进行数据验证，输出“支持 / 不支持 / 证据不足” |
| **证据链与复盘摘要** | 将事实、贡献证据、关联证据、待验证假设和验证路径组织成可复核的复盘结果 |
| **AI 分析助手** | 通过自然语言理解用户问题，并自动组织后续分析路径 |

## 关于项目

这些项目用于展示产品思考、方案设计和 AI 产品化能力。

Demo、数据和架构均为作品集中的原型 / 概念验证，不代表已经接入真实生产环境。当前在线智析 Demo 为 **纯前端浏览器 Demo**；关键计算由 JavaScript 在本地完成，LLM 层以规则化流程模拟。仓库同时保留 Streamlit 版本，用于后续继续接入真实 LLM、Schema 校验和工具路由。

我会继续围绕不同业务问题补充作品，但不会为了数量重复制作类似的 AI Demo。
