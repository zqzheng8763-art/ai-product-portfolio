## 作品目录

### 01 · 「向由心生」｜智能特价机票发现与决策平台

**关键词：** 特价机票 · 信息差 · 比价 · 价格判断 · 智能监控 · TCO · 商业模式

#### 这是一个什么产品？

「向由心生」是一款面向价格敏感型旅行用户的**特价机票发现与决策辅助平台**。

它并不试图成为另一个完整的 OTA，而是聚焦用户在购买机票之前最容易遇到的一段决策过程：**去哪、怎么买、现在买还是再等等，以及表面低价到底是不是实际低价。**

产品将分散的航班价格、历史价格、航司规则和促销信息进行整合，通过搜索、比较、价格追踪和真实成本计算，帮助用户更高效地找到合适的机票并做出购买判断。

#### 为什么做这个产品？

在寻找特价机票时，用户通常面临两个核心问题：

**1. 信息分散，找到“便宜的票”很难。**  
不同 OTA、航司官网和促销渠道的价格与活动分散在不同平台，用户往往需要反复搜索、比较，才能找到相对合适的方案。

**2. 看到“低价”并不等于真的划算。**  
廉航等特价机票经常伴随行李、选座、退改签等附加规则。用户不仅需要知道票价是多少，还需要知道**最终要付多少钱，以及当前价格是否值得购买。**

因此，这个产品希望解决的并不是单纯的“机票搜索”，而是：

> **让用户更容易发现特价，也更容易判断这个特价到底值不值得买。**

#### 核心功能

| 功能 | 说明 |
| --- | --- |
| **特价机票搜索** | 支持明确目的地，也支持“任何目的地”“一个月内”“3 天”等模糊条件，帮助用户发现低价出行机会 |
| **价格比较与趋势查看** | 展示不同航班的价格信息，并结合历史价格帮助用户判断当前价格所处的位置 |
| **真实总价（TCO）计算** | 将裸票、行李、选座等附加费用纳入计算，减少“低价裸票”带来的信息误导 |
| **购买 / 观望建议** | 根据价格、历史走势、库存和促销等信息，为用户提供更直观的购买时机判断 |
| **我的关注** | 用户可以关注航线或航班，持续跟踪价格变化，并在达到条件时获得提醒 |
| **特价与目的地推荐** | 面向没有明确目的地的用户，推荐值得关注的低价航线和目的地，提供出行灵感 |
| **全球化配置** | 支持语言、货币等偏好设置，适用于跨境及海外出行场景 |
