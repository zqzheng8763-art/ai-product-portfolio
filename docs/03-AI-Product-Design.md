# AI 产品设计｜“小太阳”

## 1. AI 在产品中的角色

“小太阳”不是通用聊天机器人，而是两个具体业务能力的统一 AI 入口：

- **推荐型 AI**：帮助用户发现值得去的目的地。
- **决策型 AI**：帮助用户判断当前价格是否值得买。

## 2. 决策链路

```text
用户搜索条件
   ↓
航班 / 价格 / 规则数据
   ↓
特征计算
   ├─ 历史价格水位
   ├─ 时序预测
   ├─ 实时库存热度
   └─ 促销与补贴
   ↓
LLM 生成
   ↓
买 / 等 + 信心指数 + 理由
```

## 3. 为什么不能只让 LLM 判断

价格预测与交易决策依赖实时数据。LLM 更适合作为“解释与决策呈现层”，而不是直接充当价格事实来源。

因此产品把结构化数据、算法预测和规则计算放在 LLM 前面，由 LLM 完成最终的自然语言表达。

## 4. TCO 产品逻辑

```text
非结构化航司规则
        ↓
NLP / LLM 信息抽取
        ↓
结构化规则 JSON
        ↓
TCO 计算引擎
        ↓
可解释价格账单
```

## 5. AI 输出规范

AI 决策结果要求具备：

- 明确结论
- 信心指数
- 关键数据依据
- 必要时给出风险提示

这样做的目的，是让用户能够理解“AI 为什么这么建议”，而不是只得到一句无法验证的答案。
