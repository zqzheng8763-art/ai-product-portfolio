# PRD｜「向由心生」智能特价机票发现与决策平台

> V1.0 · 产品需求文档整理版

## 1. 项目概述

### 1.1 背景

用户寻找特价机票时，主要面临两类问题：

1. **信息孤岛与信息差**：OTA 与航司官网价格、促销信息分散，需要多平台比价。
2. **规则复杂与决策困难**：廉航票价常伴随行李、退改签、选座等规则，用户难判断当前价格是否值得购买。

### 1.2 产品定位

基于大数据与 AI 大模型的一站式特价机票发现与智能决策辅助平台，将“找票、比价、猜价格”转化为“买或等”的决策辅助。

### 1.3 核心业务目标

**用户侧**：降低寻找特价机票的时间成本，提升购买高性价比机票的成功率。

**商业侧**：通过查价监控、订阅提醒、CPS 导流、VIP 与 DaaS 实现商业化。

## 2. 用户与场景

| 用户 | 主要诉求 |
| --- | --- |
| 价格敏感用户 | 尽可能低价出行 |
| 高频出行者 | 持续寻找高性价比航线 |
| 无目的地旅行者 | 从“哪里便宜”获得旅行灵感 |
| 家庭用户 | 综合比较多人出行的真实成本 |

### 场景 A：等降价

明确目的地 → 当前价格偏高 → 创建监控 → AI 判断“买 / 等” → 价格触发阈值 → 提醒购买。

### 场景 B：找灵感

输入出发地 + 时间范围 + 天数 → 泛意图搜索 → 推荐 TOP 目的地 → AI 推荐理由 → 查看价格与规则 → 下单。

## 4. AI 需求

### 推荐种草

结合 POI、季节性活动与用户画像，生成 60-100 字推荐文案。

### 决策辅助

LLM 输入四类特征：

1. 历史价格水位
2. 时序预测涨跌率
3. 实时库存热度
4. 促销日历与补贴信息

输出不超过 100 字，采用“结论 + 信心指数 + 理由 + 风险提示”的格式。

## 5. TCO

系统需从航司附加费规则中结构化提取：行李额度、阶梯计费、选座费、儿童 / 婴儿票比例等。

TCO 计算包含成人 / 儿童 / 婴儿人数、行李、是否连座等变量。

目标：点击“计算真实总价”后 800ms 内返回可解释的账单结果。

## 6. 性能要求

泛意图搜索需支持高并发，采用 ES 搜索中心与 Redis 热点缓存；预计算国内出发的全球底价 TOP 200，目标 P95 ≤ 1.5s。

“较昨日涨跌”不采用分秒级即时价格，而使用昨日最低价或日终结算价作为稳定基准。
