# 「向由心生」｜智能特价机票发现与决策平台

> AI-powered flight deal discovery & decision support

一个面向价格敏感型旅行用户的智能特价机票发现与决策辅助平台。

[🚀 访问产品 Demo](https://ticket-venture-space.nocode.host)

## 一句话定位

通过全网价格聚合、历史价格分析、AI 规则解析与总出行成本（TCO）精算，把用户原本需要反复“找票、比价、猜价格”的过程，转化为更直观的“买 / 等”决策。

## 为什么不是再做一个 OTA？

这个项目把产品切入点放在**交易前的决策环节**。

- OTA 擅长完成交易，但用户仍需要自己判断“现在是不是便宜”。
- 通用大模型可以理解自然语言，但缺少稳定的实时航班价格与规则数据。
- 廉航裸票价格可能很低，但行李、选座等附加成本会改变最终决策。

因此产品核心回答三个问题：

> **去哪更划算？现在买还是等？真实总价到底是多少？**

## 核心用户与场景

### 用户

- 价格敏感型 / 预算有限用户
- 高频出行者
- 无目的地旅行用户
- 家庭旅行用户

### 场景 A：有目的地，但不确定是否该买

明确目的地 → 当前价格偏高 → 创建监控 → AI 判断“买 / 等” → 价格触发阈值 → 提醒购买。

### 场景 B：没有明确目的地，先寻找旅行灵感

输入出发地 + 时间范围 + 天数 → 泛意图搜索 → 推荐高性价比目的地 → AI 推荐理由 → 查看价格与规则 → 跳转交易。

## 产品能力

| 能力 | 产品设计 |
| --- | --- |
| 泛意图搜索 | 支持“任何目的地”“一个月内”“3 天”等模糊条件 |
| AI 决策建议 | 输出“购买 / 观望”结论、信心指数与依据 |
| 价格趋势 | 综合历史价格、库存热度、节假日与促销信息 |
| TCO 精算 | 将裸票、行李、选座、机建燃油等纳入真实总价 |
| 智能监控 | 关注航线后持续追踪价格，并用红 / 黄 / 绿灯辅助判断 |
| AI 种草 | 根据目的地 POI 与用户偏好生成个性化推荐理由 |
| 商业化 | VIP + CPS 导流 + B2B 数据订阅 / DaaS |

## AI 产品设计

“小太阳”不是通用聊天机器人，而是两个具体业务能力的统一 AI 入口：

1. **推荐型 AI**：帮助用户发现值得去的目的地。
2. **决策型 AI**：帮助用户判断当前价格是否值得买。

核心决策链路：

```text
用户搜索条件
   ↓
航班 / 价格 / 规则数据
   ↓
特征计算
   ├─ 历史价格水位
   ├─ 时序预测
   ├─ 实时库存热度
   └─ 促销与补贴
   ↓
LLM 生成
   ↓
买 / 等 + 信心指数 + 理由
```

AI 不直接充当价格事实来源，而是基于结构化数据、算法预测和规则计算完成解释与决策呈现。

## TCO：从“最低裸票价”到“真实总价”

廉航场景下，产品将复杂航司规则结构化，并通过计算引擎输出可解释账单：

```text
非结构化航司规则
        ↓
NLP / LLM 信息抽取
        ↓
结构化规则 JSON
        ↓
TCO 计算引擎
        ↓
可解释价格账单
```

## 产品架构

```text
全球化数据采集层
        ↓
AI 大模型引擎「小太阳」
        ↓
核心业务应用层
        ↓
商业变现层
```

底层数据包括价格监控、航司规则 / 政策、多语言、多币种、汇率和目的地知识等；业务层覆盖探索搜索、价格趋势、关注监控和 AI 推荐。

## 商业化

- **VIP**：航线监控容量、更长预测窗口、完整 TCO 精算、低价提醒等。
- **CPS 导流**：平台聚焦交易前决策，最终交易回流 OTA / 航司。
- **B2B / DaaS**：在严格脱敏前提下沉淀搜索意图、比价行为和预测结果，形成趋势报告与 API 数据产品。

## 指标与路线图

核心指标围绕三层建立：

- **行为**：泛意图搜索使用率、AI 唤醒率、有效多轮对话率
- **转化**：精选航线点击 / 关注、AI 建议采纳、VIP 点击与付费
- **模型**：AI 决策预测正确率、价格预测 MAE、趋势方向命中率

路线：

- **Phase 1**：泛意图搜索 + 关注监控 + 历史价格 + AI 决策，验证核心闭环
- **Phase 2**：自然语言查票 + 目的地种草 + 家庭多人 TCO
- **Phase 3**：VIP + 全球多语言 / 多币种 + 海外华人与入境游拓展
